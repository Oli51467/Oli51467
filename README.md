## Featured Project

### [Trend Studio](https://github.com/Oli51467/trend-studio)

An evidence-first A-share research workspace built with Vue 3, FastAPI and PostgreSQL. It combines current market snapshots, bounded market context and a restricted multi-Agent decision workflow with frozen Evidence Packs, deterministic Python aggregation, append-only audit trails, and on-demand PDF/Markdown research reports.

- 🤖 Restricted DeepAgents + LangGraph fixed-slot orchestration
- 📊 Native daily and intraday market structure with explicit unavailable/degraded states
- 🔎 Auditable evidence, source coverage, vote history and decision replay
- 📄 Completed-consensus research report export in PDF and Markdown
